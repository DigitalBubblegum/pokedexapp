# Pokédex App

This Pokédex app is a web application built with React with TailwindCSS. It allows users to browse and search for information about various Pokémon using data fetched from the [PokeAPI](https://pokeapi.co/).

## Installation

Before running the Pokédex app, make sure you have Node.js and npm installed on your system.

1. Clone this repository to your local machine using:

`git clone https://github.com/DigitalBubblegum/pokedexapp.git`


2. Navigate into the project directory:

`cd pokedexapp`


3. Install dependencies using npm:

`npm install`


## How to Run

Once you have installed the dependencies, you can run the Pokédex app locally on your machine.

1. Start the development server:

`npm start`


2. Open your web browser and go to [http://localhost:3000/pokedexapp](http://localhost:3000/pokedexapp) to view the Pokédex app.

## Usage

- Upon launching the Pokédex app, you will be presented with a search bar.
- Enter the name of a Pokémon and see it's information. 

## Features

- **Search**: Search for Pokémon by name.
- **Detailed View**: View detailed information about each Pokémon, including its types, abilities, and base stats.

## Technologies Used

- React
- TailwindCSS
- PokeAPI
